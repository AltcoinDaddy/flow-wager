KEY CHANGES MADE:
================================================================================

1. IMPORTS ADDED

     optionA: "",

   To:
     options: ["", ""],

   - Check options.length >= 2 and <= 10

   - Check options are unique (case-insensitive)

4. STEP 1 UI
   - Replaced 2-column grid with dynamic list
   - Each option gets:
     * Badge showing "Option 1", "Option 2", etc.
     * Input field
     * Remove button (only if more than 2 options)
   - Added "+ Add Option" button (disabled at 10 options)
   - Added option counter showing current/max

5. TRANSACTION ARGS
   Old: arg(marketData.optionA, t.String), arg(marketData.optionB, t.String)
   New: arg(marketData.options, t.Array(t.String))

6. MARKET DATA PREP
   Old: optionA: formData.optionA.trim(), optionB: formData.optionB.trim()
   New: options: formData.options.map((o) => o.trim())

7. REVIEW PAGE (STEP 4)
   - Changed from 2 static badges to dynamic badge list
   - Options get colored based on index (green, red, blue rotation)
   - Wrapping layout for many options
